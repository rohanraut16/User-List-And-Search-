# User Directory Search

A simple user directory project built using HTML, CSS, and JavaScript.

The project dynamically displays user cards from a JavaScript array and filters users in real time based on name or email.

## Features

- Dynamic user rendering using JavaScript
- Real-time search filtering
- Search users by name or email
- Responsive user card layout
- DOM manipulation practice project

## Built With

- HTML
- CSS
- JavaScript

## Project Structure

```bash
├── img
├── index.html
├── style.css
└── script.js
```

## How It Works

- User data is stored inside an array of objects.
- JavaScript creates and renders all user cards dynamically.
- The search input filters matching users instantly while typing.
